# Codewars Solutions

This repository contains my Python solutions for the Codewars Solutions Assignment.

## Challenges completed

- Even or Odd
- Convert a Number to a String
- Remove String Spaces
- Vowel Count

## Files

- `codewars_solutions.py` — Python solutions for all four required Codewars challenges.

## How to run

1. Clone this repository.
2. Open a terminal in the project folder.
3. Start Python:

   ```bash
   python
   ```

4. Import and test a function:

   ```python
   from codewars_solutions import even_or_odd
   print(even_or_odd(2))
   ```
