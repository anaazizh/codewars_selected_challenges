# Codewars Solutions

This repository contains my Python solutions for the Codewars Solutions Assignment.

## Challenges completed

- Roman Numerals Encoder
- Insure an Investment
- Sum of Digits / Digital Root
- Product of consecutive Fib numbers

## Files

- `codewars_solutions.py` — Python solutions for all four Codewars challenges.

## How to run

1. Clone this repository.
2. Open a terminal in the project folder.
3. Start Python:

   ```bash
   python
   ```

4. Import and test a function:

   ```python
   from codewars_solutions import solution
   print(solution(1990))
   ```
