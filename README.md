# Codewars Selected Challenges

SE Foundations Codewars knowledge check assignment.

## Included Challenges

- **Even or Odd** — `even_or_odd(number)` returns `"Even"` or `"Odd"`.
- **Convert a Number to a String** — `number_to_string(num)` returns the string form of a number.
- **Remove String Spaces** — `no_space(x)` removes all spaces from a string.
- **Vowel Count** — `get_count(sentence)` counts lowercase vowels (a, e, i, o, u).

## Setup

Requires Python 3. No external dependencies.

## Viewing / Running

View the solutions:

```bash
cat codewars_solutions.py
```

Run the built-in verification:

```bash
python3 codewars_solutions.py
```

A successful run prints `All verifications passed.`
